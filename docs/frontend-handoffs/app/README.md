# App audience reports

App means the **Family, Caregiver and Elderly clients**. Care Home Owner and
administrative web portal reports belong under Admin, not here.

Use `family/`, `caregiver/`, `elderly/` or `shared/`, followed by phase name and a
dated topic file, as defined in the [handoff conventions](../README.md).
No mobile-screen audit or mobile implementation report has been issued for the
current portal intake. A future shared auth/notification contract handoff may be
useful to these clients, but must explicitly distinguish API contract evidence
from an actual frontend code review.
